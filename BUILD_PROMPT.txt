Project Name : NexaStudy
Tagline      : AI-Powered RAG Study Assistant with Video Generation
Author       : Nishant Gupta (23FE10CDS00506), MUJ Data Science Batch F

NexaStudy is a student-focused AI assistant powered by Retrieval-Augmented
Generation (RAG). Students upload their notes, slides, PDFs, datasets, and
images. NexaStudy extracts, chunks, embeds, and stores the content in a vector
database. When a student asks a question, the system retrieves the most relevant
chunks, reranks them with a cross-encoder, and generates a cited answer via the
Google Gemini LLM. Optionally, the answer can be turned into a narrated MP4
slide video using gTTS + MoviePy.

Create rag.py as a single Python module containing the class NexaStudyRAG.
It must implement ALL of the following:

5A. CLASS CONSTRUCTOR  __init__()
  - Read all config from environment variables via os.getenv() with defaults.
  - Call genai.configure(api_key=...) from google.generativeai.
  - Suppress FutureWarning from google.generativeai using warnings.filterwarnings.
  - Initialize a ChromaDB PersistentClient at CHROMA_PERSIST_DIR.
  - Create or get three Chroma collections:
      COLLECTION_NAME       (main knowledge store)
      FEEDBACK_COLLECTION   (student corrections)
      MEMORY_COLLECTION     (conversation turns)
    All collections use cosine distance: metadata={"hnsw:space": "cosine"}
  - Initialize GoogleGenerativeAIEmbeddings with the embedding model.
    Use a fallback list: ["models/gemini-embedding-001", "gemini-embedding-001"]
    Try each until one succeeds (embed a test string "test").
  - Initialize CrossEncoder(RERANKER_MODEL) — catch ImportError, set to None.
  - Store generation model candidates (try each at generation time):
      ["models/gemini-flash-lite-latest", "gemini-flash-lite-latest",
       "models/gemini-2.5-flash-lite",    "gemini-2.5-flash-lite",
       "models/gemma-3-1b-it",            "gemma-3-1b-it"]
  - Initialize RecursiveCharacterTextSplitter with chunk_size, chunk_overlap,
    and separators ["\n\n", "\n", ". ", "! ", "? ", " ", ""].

5B. FILE INGESTION  ingest_file(filename: str, content: bytes) -> int
  Supported extensions and their parsers:
    .pdf   -> PyMuPDF (fitz) with 3-layer OCR (see 5C below)
    .pptx  -> python-pptx: extract text from all shapes across all slides;
              include slide number in metadata; OCR any embedded images.
    .docx  -> python-docx: extract text from paragraphs and tables.
    .txt   -> decode as UTF-8 with latin-1 fallback.
    .md    -> same as .txt.
    .csv   -> pandas read_csv, convert to string.
    .png / .jpg / .jpeg / .bmp / .webp -> OCR the raw bytes via _ocr_image().
  After parsing, split text into chunks, embed all chunks in one batch call,
  upsert to Chroma with metadata: {filename, chunk_index, source, timestamp}.
  Return the count of chunks stored.
  Raise ValueError for unsupported extensions.

5C. PDF OCR PIPELINE  _extract_pdf_text(data: bytes) -> str
  For each page in the PDF:
    1. Extract the text layer via page.get_text("text").
    2. Iterate embedded images on the page (page.get_images(full=True)):
       - Extract the xref image as bytes.
       - Run _ocr_image() on it and append the result.
    3. If the combined text from steps 1+2 has fewer than OCR_MIN_TEXT_THRESHOLD
       characters, render the full page to a pixmap (matrix=fitz.Matrix(2,2))
       and run _ocr_image() on the PNG bytes of the pixmap.
    4. Merge and join all page texts with "\n".

5D. OCR  _ocr_image(image_bytes: bytes) -> str
  Try Tesseract first (pytesseract.image_to_string). If Tesseract raises
  TesseractNotFoundError or any OSError, fall back to Gemini vision:
    model = genai.GenerativeModel("gemini-2.0-flash-lite")
    response = model.generate_content([
        "Extract all text from this image. Return only the extracted text.",
        {"mime_type": "image/png", "data": base64.b64encode(image_bytes).decode()}
    ])
    return response.text
  Return "" on any other exception.

5E. HYBRID RETRIEVAL  retrieve(query: str, session_id: str) -> List[dict]
  a) Dense retrieval: embed query -> query_embeddings, call
     self.collection.query(query_embeddings=[q_emb], n_results=TOP_K_RETRIEVAL)
  b) Keyword retrieval: call self.collection.query with
     where_document={"$contains": query_lower} and n_results=TOP_K_RETRIEVAL//2
  c) Feedback retrieval: embed query -> query feedback_collection similarly.
  d) Merge all candidates, deduplicate by chunk id, keep unique chunks.
  Return list of dicts with keys: {id, text, metadata, score}.

5F. RERANKING  rerank(query: str, candidates: List[dict]) -> List[dict]
  If self.reranker is not None:
    pairs = [(query, c["text"]) for c in candidates]
    scores = self.reranker.predict(pairs)
    sort candidates by score descending, return top TOP_K_RERANKED.
  Otherwise return candidates[:TOP_K_RERANKED].

5G. MEMORY  save_memory() / format_memory_as_string()
  After each chat turn, save user query and assistant answer as separate
  documents to MEMORY_COLLECTION with metadata: {session_id, role, timestamp}.
  On retrieval, fetch the MAX_MEMORY_TURNS most recent turns for the session,
  ordered by timestamp (use metadata filter: where={"session_id": session_id}).
  format_memory_as_string() returns a string of "User: ...\nAssistant: ..."
  pairs for injection into the prompt.

5H. FEEDBACK  record_feedback(query, bad_answer, correction, session_id)
  Store an entry in FEEDBACK_COLLECTION with the corrected answer as the
  document and metadata: {query_hash: md5(query), session_id, timestamp}.

5I. PROMPT BUILDING  build_prompt(query, context_block, memory_str, feedback_str)
  Construct the full prompt string using this exact template:

  You are an expert AI study assistant helping a student understand
  their study materials. You have access to the student's uploaded
  documents and conversation history.

  CONVERSATION HISTORY (most recent {MAX_MEMORY_TURNS} turns):
  {memory_str}

  RETRIEVED DOCUMENT CONTEXT:
  {context_block}

  PREVIOUS CORRECTIONS / FEEDBACK:
  {feedback_str}

  STUDENT QUESTION:
  {query}

  INSTRUCTIONS:
  1. Answer ONLY based on the provided context above.
  2. If the answer is not in the context, say:
     "I could not find this in your uploaded documents. Here is
      what I know generally: ..." then give a general answer.
  3. Always cite sources: [Source: {filename}, Page/Slide {n}]
  4. Structure: direct answer first -> supporting details -> summary.
  5. For concepts, explain step by step in simple language.
  6. Never fabricate. Never say you cannot help.
  7. Match the student's language (Hindi, etc. if they write in it).
  8. Answer the exact question first, stay tightly relevant.
  9. Do not expose local file system paths unless explicitly asked.
  10. For fact questions respond in 2-4 sentences max unless asked.
  11. Present most important details first.
  12. Never include unrelated file structure or dataset counts.

5J. ANSWER GENERATION  generate_answer(query: str, session_id: str) -> dict
  1. Call retrieve() -> rerank() to get top chunks.
  2. Build context_block: number each chunk, include source metadata.
  3. Get memory_str from format_memory_as_string().
  4. Get feedback_str from feedback_collection retrieval.
  5. Call build_prompt() to assemble the full prompt.
  6. Try each generation_model_candidate:
       model = genai.GenerativeModel(candidate)
       response = model.generate_content(prompt)
     Use the first successful response.
  7. Call save_memory(query, answer_text, session_id).
  8. Return dict: {answer, sources, chunks_used, model, scores}
     - sources: deduplicated list of {filename, chunk_index}
     - chunks_used: list of chunk text snippets (first 200 chars each)
     - scores: reranker scores

5K. UTILITY METHODS

    Query collection for all documents, extract unique filenames from metadata.
  delete_file(filename: str)

    delete those IDs.
  get_stats() -> dict
    Return {total_chunks, total_files, embedding_model, generation_model,
            chroma_persist_dir, collection_name}.

Create video_gen.py with class VideoGenerator. No GPU required.

Pipeline:
  1. build_script(answer_text) -> List[Slide]
     Split answer_text by "\n\n" into paragraphs.
     First paragraph = intro slide titled "Summary".
     Remaining paragraphs grouped 2 per slide, titled "Key Points", "Details", etc.
     Each Slide has: title (str), body (str).

  2. render_slide(slide: Slide) -> bytes  (PNG image bytes)
     Use Pillow (PIL) to draw a 1280x720 image:
       - Background: dark navy  RGB(15, 23, 42)
       - Blue accent bar at top: 8px tall, full width, RGB(37, 99, 235)
       - Title text: near-white RGB(248,250,252), font size ~52, bold if possible
         Wrap at 20 chars/line. Top padding 80px.
       - Body text: same color, font size ~32
         Wrap at 36 chars/line. Below title with line spacing 1.5.
       - Slide number in bottom-right corner, small gray text.
     Return PNG bytes via io.BytesIO.

  3. generate_audio(slide: Slide) -> bytes  (MP3 bytes)
     Combine slide.title + " " + slide.body as TTS input.
     Use gTTS(text=..., lang="en", slow=False).
     Return MP3 bytes via BytesIO.

  4. generate(answer_text: str, session_id: str) -> str  (path to MP4)
     - Call build_script -> get list of Slide objects.
     - Use a ThreadPoolExecutor to render PNG + generate MP3 in parallel per slide.
     - For each slide, determine duration = max(SLIDE_DURATION_SEC, estimated_audio_sec).
     - Use moviepy to:
         a. Create an ImageClip from PNG bytes for the calculated duration.
         b. Create an AudioFileClip from the MP3 bytes (written to a temp file).
         c. Set the audio on the ImageClip.
         d. Concatenate all clips with concatenate_videoclips().
         e. Write final MP4 to output_dir/nexastudy_{session_id}_{timestamp}.mp4
            using write_videofile(..., codec="libx264", audio_codec="aac").
     - Clean up temp files.
     - Return the absolute path to the MP4 file.

"GEMINI_API_KEY not found"
  -> Ensure .env file exists in root with GEMINI_API_KEY set.
  -> Do NOT add quotes around the value.

"Tesseract not found"
  -> Install: brew install tesseract  (macOS)
  -> Or just ignore it -- Gemini OCR fallback activates automatically.

"ChromaDB persistence error"
  -> Check CHROMA_PERSIST_DIR permissions.
  -> Delete chroma_db/ and let it re-create.

"Model not found" (Gemini error)
  -> The system tries 6 model candidates automatically.
  -> Ensure your API key has access to Gemini Flash models.
  -> Free tier keys work fine with gemini-flash-lite-latest.

  -> Ensure Node.js 18+: node --version
  -> Try: npm install --legacy-peer-deps

"Video generation fails"
  -> Ensure moviepy is installed: pip install moviepy
  -> Ensure ffmpeg is installed: brew install ffmpeg  (macOS)
  -> Check ./videos/ directory exists and is writable.

  ARCHITECTURE SUMMARY (for agent reference)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  INGESTION PIPELINE:
  Upload -> Parser (PyMuPDF / pptx / docx / pandas / Pillow)
         -> OCR layer (Tesseract -> Gemini fallback)
         -> RecursiveCharacterTextSplitter (800 chars, 150 overlap)
         -> GoogleGenerativeAIEmbeddings (gemini-embedding-001)
         -> ChromaDB PersistentClient (cosine, 3 collections)

  QUERY PIPELINE:
  Query  -> Embed query
         -> Dense retrieval    (Chroma query_embeddings)
         -> Keyword retrieval  (Chroma where_document $contains)
         -> Feedback retrieval (corrections collection)
         -> Merge + deduplicate candidates
         -> CrossEncoder reranking (ms-marco-MiniLM-L-6-v2)
         -> Top-4 chunks -> build_prompt()
         -> genai.GenerativeModel (flash-lite, with fallback chain)
         -> Cited answer -> save to memory

  VIDEO PIPELINE:
  Video  -> build_script (slide objects from answer paragraphs)
         -> render_slide (Pillow 1280x720 PNG frames)
         -> generate_audio (gTTS MP3 per slide)
         -> Stitch (MoviePy ImageClip + AudioFileClip -> MP4)
